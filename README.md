# TuxunSafari

在 macOS 上连接 Safari 中已经打开的图寻对局，读取当前全景的经纬度，等待指定秒数后提交位置。脚本通过 AppleScript 执行页面 JavaScript，不模拟鼠标或键盘，也不需要打开 Codex。

## 运行环境

- macOS、Safari 和 Python 3。
- Safari 已登录图寻，并在当前标签页打开 `tuxun.fun/party/...` 或 `tuxun.fun/solo/...` 对局。
- Python 只用标准库，无需安装 pip 包。

## 开始使用

1. 下载仓库，解压到本地文件夹。
2. 在 Safari 当前标签页打开图寻对局。
3. 双击 `启动.command`，输入本次等待秒数；直接回车则使用配置文件中的默认值。
4. 保持游戏标签页打开。终端会显示坐标、提交动作和游戏确认状态。

按 **Ctrl+C** 停止。脚本退出后不会继续自动提交。

如果启动文件没有执行权限，在项目目录运行：

```sh
chmod +x 启动.command
```

也可以直接从终端启动：

```sh
python3 tuxun.py --delay 10
```

## 调整等待时间

默认读到坐标后等 10 秒再提交，位置在原坐标周围 100 米半径内随机偏移。修改 `config.json` 可以更改默认值：

```json
{
  "delay_mode": "fixed",
  "delay_seconds": 10,
  "delay_min_seconds": 8,
  "delay_max_seconds": 15,
  "offset_meters": 100
}
```

将 `10` 改成需要的秒数即可。启动时输入的秒数或 `--delay` 参数只对本次运行生效，会覆盖配置文件。

实际提交可能有约 1–2 秒的轮询误差。等待时间过长可能错过游戏倒计时；脚本会遵守设定，不提前提交。

## Safari 权限

首次运行时，如果 macOS 询问终端是否可以控制 Safari，选择允许。

Safari 还需要启用“开发 → 允许来自 Apple 事件的 JavaScript”。如果没有“开发”菜单，先在 Safari 设置的“高级”中显示开发者功能；不同版本的选项文字可能略有区别。

仅检查连接，不选点、不提交：

```sh
python3 tuxun.py --check
```

## 工作方式

脚本从页面当前轮次模型取得全景 ID，再读取全景坐标。百度和腾讯全景使用网站对应的信息接口，Google 全景使用街景坐标服务。取得坐标后，脚本调用页面现有的选点状态和“确定选择”按钮提交。

启动后会锁定当前对局 URL，切换到其他标签页不会改选目标。游戏结束后自动停止；刷新页面或进入新对局后，可以重新启动。脚本不会自动匹配、创建房间或发送聊天。

## 文件

| 文件 | 用途 |
| --- | --- |
| `启动.command` | 双击启动，也可临时输入等待秒数 |
| `config.json` | 保存默认等待时间 |
| `tuxun.py` | 连接 Safari、轮询状态并输出日志 |
| `runner.js` | 读取全景坐标，选点并提交 |
| `使用说明.md` | 本地使用说明 |
| `last-run.log` | 运行时生成的日志，每次启动覆盖，不纳入 Git |

## 验证情况与限制

百度全景已在实际派对房间验证过坐标读取及满分提交；Google 全景已验证坐标读取。腾讯全景沿用网站对应接口，尚未在本次测试中验证。

本地测试覆盖了选点、等待 10 秒后点击提交、确认状态和游戏结束后停止。网站改版后，内部组件或接口可能变化，届时需要调整脚本。

## 随机等待和位置偏移

双击启动后，可以输入固定等待秒数，或输入 `r` 选择随机等待。随机模式可以临时填写最短、最长秒数；直接回车则使用配置区间。随后可以输入最大偏移半径，单位是米，直接回车使用配置值。

配置项说明：

| 配置项 | 含义 |
| --- | --- |
| `delay_mode` | `fixed` 固定等待，`random` 每轮随机等待 |
| `delay_seconds` | 固定等待秒数，默认 10 |
| `delay_min_seconds` | 随机等待的最短秒数，默认 8 |
| `delay_max_seconds` | 随机等待的最长秒数，默认 15 |
| `offset_meters` | 位置偏移的最大半径，默认 100 米；0 表示不偏移 |

位置在指定半径的圆形范围内按面积均匀随机选取，距离和方向每轮重新生成。偏移半径表示上限，不是每次偏移的固定距离。脚本按球面距离计算坐标，跨越经度边界时会归一化经度；随机点可能落在水面或道路外。

例如，每轮随机等 8–15 秒，提交位置在原坐标周围 200 米以内：

```sh
python3 tuxun.py --random-delay 8 15 --offset-meters 200
```

固定等 10 秒、不偏移：

```sh
python3 tuxun.py --delay 10 --offset-meters 0
```

等待参数允许 0–3600 秒，偏移半径允许 0–100000 米。随机区间的最短时间不能超过最长时间。日志显示本轮生成的坐标、偏移距离和等待时长；随机值在读取坐标后生成一次，重试提交时不会重新抽取。以上等待时间仍受轮询误差影响。
